# 🌤 Smart Interactive Weather Dashboard

A modern and interactive Weather Dashboard built using Python, Streamlit, OpenWeatherMap API, Folium Maps, and Data Visualization tools. The application provides real-time weather updates, forecasts, interactive maps, graphs, and a user-friendly dashboard experience.

---

# 🚀 Features of the Weather App

## 🔐 Login System

* Secure login page before accessing the dashboard
* User authentication interface
* Dashboard opens only after successful login

---

## 🌍 City Search

* Search weather by entering any city name
* Real-time weather fetching using API
